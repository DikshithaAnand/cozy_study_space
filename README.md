# 🌙 Cozy Study Space

**Cozy Study Space** is a minimal, aesthetic, and calming productivity web app designed to help users focus gently—without stress or pressure.  
It promotes mindful studying by encouraging **one goal at a time**, paired with a cozy focus timer, ambient sound, and eye-friendly themes.

This project blends **mental well-being with productivity**, inspired by cozy study aesthetics and slow, intentional work.

> **FOCUS TIME, WITHOUT BURNOUT**

---

## ✨ Features

### ⏱️ Focus Timer
- Start, pause, and restart controls  
- **25-minute** Pomodoro focus mode  
- **50-minute** deep focus mode  

### 🌙 Day & Night Mode
- Soft beige **Day Mode**  
- Warm coffee-brown **Night Mode**  
- Designed to reduce eye strain during long study sessions  

### 🌧️ Ambient Rain Sound
- Optional calming rain audio  
- Enhances focus and relaxation  

### 📝 One Goal at a Time
- Set a single task to stay focused  
- Goal is automatically saved using `localStorage`  

### 🌱 Gentle User Experience
- Encouraging messages instead of pressure  
- No harsh alarms or distractions  
- Clean, minimal, and cozy UI  

---

## 🎨 Design Philosophy

- Warm, muted color palette  
- Rounded UI components  
- Soft shadows and comfortable spacing  
- Emotion-first productivity  
- Designed to reduce stress, burnout, and anxiety  

> *“You are doing enough 🌱”*
